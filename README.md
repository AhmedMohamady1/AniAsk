# AniAsk

A full-stack anime platform featuring an AI-powered conversational chatbot for querying anime and manga data via the [AniList](https://anilist.co) GraphQL API, paired with a type-safe authentication and watchlist tracking backend.

---

## Architecture Overview

AniAsk is structured into three specialized services:

| Service | Directory | Tech Stack | Port | Purpose |
|---|---|---|---|---|
| **AI Chatbot API** | `Chatbot/` | FastAPI, LangGraph, Google Gemini, AniList GraphQL | `8000` | Natural language conversational agent with context memory & tools |
| **Backend REST API** | `backend/` | Express.js 5, TypeScript, PostgreSQL 17, Drizzle ORM, Resend | `4000` | User authentication (JWT + refresh rotation), OTP verification, anime watchlist tracking |
| **Frontend UI** | `frontend/` | React 19, TypeScript, Vite, Dexie.js (IndexedDB) | `5173` | Interactive chat interface with on-device conversation persistence & search |
| **Database** | `backend/docker-compose.yml` | PostgreSQL 17 Alpine | `5432` | Relational store for users, refresh tokens, and watchlist tracker entries |

---

## Key Features

### 1. AI Chatbot (`Chatbot/`)
- **Natural Language Anime Exploration:** Translates conversational questions into precise AniList GraphQL queries without needing to memorize schemas or IDs.
- **Context-Aware Memory:** Multi-turn memory retains conversation context (e.g. *"Who voices Okabe?"* followed by *"What other roles has he done?"*).
- **Specialized AniList Tools:**
  - `search_anime`: Filter by title, genre, season, year, score, format, and status.
  - `get_anime_details`: Retrieve in-depth characters, staff, Japanese voice actors with portraits, and relations.
  - `search_studio`: Query animation studios (MAPPA, Kyoto Animation, ufotable, Wit) and fetch their top produced works.
- **Rich Media Visual Layouts:** Output includes cover posters, character/voice actor pair showcases, and interactive AniList pill badges.

### 2. Backend REST API (`backend/`)
- **Secure Authentication:** Short-lived JWT access tokens and long-lived refresh tokens with rotation and HTTP-only cookie storage.
- **Email Verification & OTP:** 6-digit one-time passcodes delivered via **Resend** with cooldown and brute-force protection.
- **Personalized Watchlist Tracking:** Full CRUD tracking for anime watching status (`watching`, `completed`, `on_hold`, `dropped`, `planning`) with custom scores.
- **AniList Discovery Endpoints:** REST endpoints proxying trending, popular, top-rated, and seasonal anime feeds.

### 3. Frontend Web App (`frontend/`)
- **On-Device Storage (Privacy-First):** Past conversations and messages persist 100% locally in your browser using **IndexedDB (via Dexie.js)**.
- **AI Conversation Summaries:** Automatically generates concise 3–6 word titles via Gemini after your first message exchange.
- **Client-Side TF-IDF Search:** Real-time cosine similarity search engine to filter and search past conversations instantly.
- **Interactive Media Cards:** Glassmorphic anime list cards, role badges, and hero posters.

## Environment Configuration

### 1. Root & Chatbot Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
cp .env.example Chatbot/.env
```

Open `.env` (and `Chatbot/.env`) and add your Gemini API key:
```env
GOOGLE_API_KEY=your_actual_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
ANILIST_API_URL=https://graphql.anilist.co
```

### 2. Backend Environment
Copy `backend/.env.example` to `backend/.env`:
```bash
cp backend/.env.example backend/.env
```

Ensure secure secrets and configuration in `backend/.env`:
```env
PORT=4000
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/aniask
NODE_ENV=development
ACCESS_TOKEN_SECRET=your_secure_64_byte_hex_secret
REFRESH_TOKEN_SECRET=your_secure_64_byte_hex_secret
OTP_EXPIRATION=10m
ACCESS_TOKEN_EXPIRATION=15m
REFRESH_TOKEN_EXPIRATION=7d
ANILIST_API_URL=https://graphql.anilist.co
RESEND_API_KEY=your_resend_api_key_here
EMAIL_FROM=onboarding@resend.dev
```

## Installation

### 1. Set up Python Virtual Environment (Chatbot)
From the project root:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r Chatbot/requirements.txt
```

### 2. Install Backend Dependencies
```bash
npx pnpm --prefix backend install
# or: cd backend && npm install
```

### 3. Install Frontend Dependencies
```bash
npm --prefix frontend install
# or: cd frontend && npm install
```

## Running the Application

> [!TIP]
> **Deployed Backend Available:**
> The Express.js + PostgreSQL backend is already deployed live at **`https://aniask.onrender.com/`** (Health: [`https://aniask.onrender.com/health`](https://aniask.onrender.com/health)).
> If you are working on the **Chatbot** or **Frontend**, you **do not need** to run Docker or the local Express backend! Just run the Chatbot and Frontend below.

### Standard Workflow: Chatbot & Frontend

You only need **two terminals**:

#### Terminal 1 — AI Chatbot API (Port 8000)
From the project root:
```bash
source .venv/bin/activate
PYTHONPATH=Chatbot uvicorn backend.main:app --reload --port 8000
```
- **Server:** `http://localhost:8000`
- **Swagger Docs:** `http://localhost:8000/docs`
- **Health Check:** `http://localhost:8000/api/health`

#### Terminal 2 — Frontend UI (Port 5173)
From the project root:
```bash
npm --prefix frontend run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser to chat with AniAsk!

---

### Optional: Running the Express Backend Locally

*(Only required if you are actively modifying the Express authentication / tracking backend)*

1. **Launch PostgreSQL Database:**
   ```bash
   docker compose -f backend/docker-compose.yml up -d
   ```
2. **Apply Migrations:**
   ```bash
   npx pnpm --prefix backend db:migrate
   ```
3. **Start Express Server (Port 4000):**
   ```bash
   npx pnpm --prefix backend dev
   ```
   *(Note: Use `pnpm` as configured in `backend/package.json` devEngines)*
   - **Local Server:** `http://localhost:4000`
   - **Deployed Server:** `https://aniask.onrender.com/`
